# 1. Product Entitlement Enforcement Adoption

Adopt `ICommerceEntitlementClient` in the first suitable product service.

Recommended first target:
- SynqLiens / Liens service, if present

Requirements:

- use `ICommerceEntitlementClient`
- register Commerce integration through `AddCommerceIntegration(configuration)`
- register `CommerceServiceMetadata`
- keep `CommerceIntegration:Enabled=false` by default
- implement permissive fallback when Commerce is unavailable
- do not block service startup when Commerce is unavailable
- do not directly query Commerce database
- do not add billing logic into product service
- do not enforce destructively unless configuration explicitly enables enforcement

Recommended behavior:

- If Commerce integration is disabled or unavailable:
  - allow existing behavior
  - log/debug safe fallback
  - report entitlement status as unavailable/noop

- If Commerce integration is enabled:
  - resolve tenant entitlement by host tenant ID
  - check product key
  - allow access when entitlement permits
  - deny or degrade only if an explicit enforcement flag is enabled

Add configuration such as:

CommerceIntegration:
  Enabled: false
  BaseUrl: http://127.0.0.1:5030
  HostPlatformKey: legalsynq
  TimeoutSeconds: 10
  EnforcementEnabled: false

If no suitable product service exists:
- implement the reusable entitlement adoption helper/policy only
- document exact reason product wiring was deferred
