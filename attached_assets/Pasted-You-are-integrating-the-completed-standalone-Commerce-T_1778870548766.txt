# Objective

Integrate the standalone Commerce + Tenant Billing services into the LegalSynq platform while preserving them as independent bounded domain services.

This is NOT a merge/rewrite project.

This is a platform integration project.

# Critical Architecture Rule

DO NOT merge the billing domains.

Maintain separation:

Platform / SaaS Billing:
Commerce
Platform → Tenant

Tenant Billing:
Tenant → Customer / Client

These domains must remain isolated.
