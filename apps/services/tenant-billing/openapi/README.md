# Billing OpenAPI Contract — `services/billing/openapi/`

This directory holds the **canonical machine-readable OpenAPI contract** for the Billing microservice (`Billing.Api`). The contract is the integration source of truth for the future Monk BFF (MS-BILL-BFF-005) and any tenant-portal Angular client work.

## Canonical file

```
services/billing/openapi/billing-openapi.json
```

> **Status:** the file is **not committed yet** — it is generated by the script described below in any environment that has the .NET 8 SDK. The Replit workspace where this scaffold was built does not ship `dotnet`, so generation was honestly deferred to CI / a contributor laptop. There is no fabricated contract in the repo.

## Regenerate

```bash
services/billing/scripts/generate-openapi.sh
```

The script forces a tenant-safe environment for the generator:

| Variable | Forced value | Reason |
|---|---|---|
| `ASPNETCORE_ENVIRONMENT` | `Development` | Enables Swagger pipeline. |
| `BILLING_INTERNAL_TOKEN` | `dev-only-openapi-token` | Satisfies the fail-closed startup gate. **Never appears in the generated JSON.** |
| `BILLING_RUN_MIGRATIONS` | `false` | Belt-and-braces — generator must never run migrations. |
| `BILLING_ENABLE_PLATFORM_TEMPLATES` | `false` | Hides `/api/invoice-templates/platform/*` from the published contract via `HideDisabledPlatformTemplateEndpointsDocumentFilter`. |
| `BILLING_DB_CONNECTION`, `ConnectionStrings__Billing`, `ConnectionStrings__DefaultConnection` | unset | `AddBillingInfrastructure` falls through to the in-memory provider — no real socket is opened. |

## Validate the generated contract (manual drift check)

```bash
# 1. Regenerate
services/billing/scripts/generate-openapi.sh

# 2. Diff against the committed snapshot
git diff -- services/billing/openapi/billing-openapi.json
```

Any non-empty diff means the API surface drifted. Either the API change is intentional (commit the regenerated file together with the API change) or it is accidental (revert the API change before merging).

## Required tooling

- .NET 8 SDK (`dotnet --version` reports 8.x)
- Local tools restored once via `dotnet tool restore` (the script does this for you):
  - `dotnet-ef` 8.0.10
  - `swashbuckle.aspnetcore.cli` 6.8.1 — pinned to the same version as the `Swashbuckle.AspNetCore` package reference in `Directory.Packages.props`. **Bump them in lock-step.**

## Do not hand-edit

`billing-openapi.json` is a derived artifact. Hand edits will be silently overwritten by the next `generate-openapi.sh` run. To shape the contract, change one of:

- `services/billing/src/Billing.Api/Program.cs` — Swagger doc metadata, security definitions, filter registrations.
- `services/billing/src/Billing.Api/OpenApi/InternalTokenOperationFilter.cs` — applies `X-Internal-Token` requirement.
- `services/billing/src/Billing.Api/Tenancy/TenantHeaderOperationFilter.cs` — applies `X-Tenant-Id` requirement.
- `services/billing/src/Billing.Api/OpenApi/HideDisabledPlatformTemplateEndpointsDocumentFilter.cs` — hides platform-template paths.
- `services/billing/src/Billing.Api/Controllers/*.cs` — XML-doc summaries, `[ProducesResponseType]`, route attributes.

…then regenerate.

## Internal-only headers (reminder)

Both `X-Internal-Token` and `X-Tenant-Id` are **internal**. They are injected by the Monk BFF; browser clients must never send them. The published contract documents both via security schemes, applied per-operation by the operation filters listed above.
